# Diabetes Data Analysis – Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the Pima Indians Diabetes Dataset using Python. The objective is to explore the dataset, understand the distribution of different health-related attributes, identify patterns, and analyze factors associated with diabetes.

## 🎯 Objectives
- Understand the structure and characteristics of the dataset.
- Perform data cleaning and preprocessing.
- Identify missing or invalid values.
- Calculate descriptive statistics.
- Analyze relationships between different features.
- Visualize patterns and correlations in the dataset.
- Extract meaningful insights from the data.

## 📂 Dataset
The project uses the Pima Indians Diabetes Dataset.

**Dataset source:** [Diabetes Dataset – GitHub](https://raw.githubusercontent.com/salemprakash/EDA/main/Data/diabetes.csv)

The dataset contains medical and diagnostic information, including:
- Pregnancies
- Glucose
- BloodPressure
- SkinThickness
- Insulin
- BMI
- DiabetesPedigreeFunction
- Age
- Outcome (Diabetes status)

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas – Data manipulation and analysis
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical visualization

## 🔍 Analysis Performed

1. **Data Loading:** Imported the dataset using Pandas.
2. **Data Exploration:** Examined the dataset using `head()`, `tail()`, `info()`, and `describe()`.
3. **Data Cleaning:** Checked for missing values, duplicates, and invalid zero values.
4. **Statistical Analysis:** Calculated mean, median, standard deviation, minimum, and maximum values.
5. **Data Visualization:** Created histograms, box plots, count plots, and correlation heatmaps.
6. **Correlation Analysis:** Examined relationships between numerical features.
7. **Insights:** Identified patterns and observations related to diabetes outcomes.

## 📊 Key Learnings
- Understood the importance of data preprocessing before analysis.
- Learned how to identify missing and invalid values.
- Gained practical experience with statistical analysis.
- Improved understanding of data visualization techniques.
- Learned to interpret correlations and identify patterns in datasets.
